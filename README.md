# Japan Open Data Atlas

Qiita 記事「[日本のオープンデータ100選](https://qiita.com/Retro-Maid/items/d99e436fe0b19e151709)」のリンクを辿り、
**左カラム = 項目一覧 / 右カラム = 2D・3D ビジュアル** で表示するサイトです。

```bash
npm install
npm run dev        # 開発サーバー (http://localhost:5173)
npm run build      # dist/ に静的サイトを出力（相対パスなのでどこにでも置ける）
# main への push で GitHub Pages に自動デプロイ（.github/workflows/pages.yml）
```

## 集約しているデータ

| パス | 内容 | 更新方法 |
|------|------|----------|
| `data/catalog.json` | 記事の100項目すべて（分類・提供元・概要の冒頭抜粋・規約リンク・リンク先）。本文の転載は避け、詳細は元記事へ誘導 | `npm run catalog` |
| `data/snapshots/egov_orgs.json` | e-Gov データポータル: 提供組織別データセット数 | `npm run snapshots` |
| `data/snapshots/covid_weekly.json` | 新型コロナ 新規陽性者数（都道府県別・週別集計） | `npm run snapshots` |
| `data/snapshots/laws_stats.json` | e-Gov 法令: 種別 × 公布年代の件数（現行法令 全件走査） | `npm run snapshots` |
| `data/snapshots/boj_usdjpy.json` | 日本銀行: ドル円 月中平均（1973年〜） | `npm run snapshots` |
| `data/snapshots/kkj_hits.json` | 官公需情報: 都道府県別の公示件数（工事・委託・物品） | `npm run snapshots` |
| `data/snapshots/jp_traffic_accidents.json` | 警察庁 交通事故統計（最新年の本票 約29万件を 10km メッシュ・曜日×時間帯・月別に集計、死亡事故地点） | `npm run snapshots:py` |
| `data/snapshots/toei_gtfs.json` | 東京都交通局 GTFS（都営地下鉄・都電の路線、駅、都営バス停留所） | `npm run snapshots:py` |

スナップショットは、ブラウザから直接取得できない（CORS 非対応）または巨大なデータを事前に集計して保存したものです。

**自動更新**: `.github/workflows/update-snapshots.yml` が毎週月曜 03:00 JST に全スナップショットを再取得し、取得時刻以外に変化があるときだけ `main` にコミットしてサイトを再デプロイします（手動実行は Actions の *Run workflow*）。手元では `npm run snapshots:all`。交通事故データは公開済みの最新年を自動で探します。

## 共通機能

- 左: 分類アコーディオン（アイコン・色分け）/ 検索 / 種別フィルタ、右: ビジュアル。前後の項目への移動、全画面表示
- ライト/ダークテーマ切替、スマホ表示（項目一覧はメニュー化）
- 地図: 地名検索（国土地理院 地名検索API）、2D/3D 切替と起伏の強調スライダー、背景切替、時系列再生
- アメダスの観測所をクリックすると直近 24 時間の推移グラフを表示
- 地図の表示位置は URL に保存され（`#/12?v=経度,緯度,ズーム,傾き,方位`）、共有・再読込で復元されます
- ホームに「いまの日本」ライブカード（最新の地震・全国の最高/最低気温 ほか）

## 構成

```
index.html / src/main.js     2 カラム UI（左: 一覧・検索・絞り込み / 右: ビジュアル）
src/viz/registry.js          項目 ID → ビジュアル定義
src/viz/geo.js               汎用 2D/3D 地図ビュー（背景・タイル重ね・時系列再生）
src/viz/{plateau,amedas,quake,volcano,jshis}.js   地図の独自描画
src/viz/{pref3d,dashboard,procure}.js              都道府県別 3D 柱の共通ビュー
src/viz/{traffic,toei}.js                          交通事故・都営交通
src/viz/views.js             グラフ・ギャラリー
scripts/                     カタログ生成 / スナップショット取得
```

技術: Vite + MapLibre GL JS v6（背景は国土地理院タイル、3D 地形は AWS Terrain Tiles/Terrarium）。

## 注意

- MapLibre v6 のワーカーは Vite のバンドルに含まれないため、`src/viz/map-core.js` で `?url` 経由の明示指定をしています。
- `data/catalog.json` には、Qiita 記事の本文は含めず、各項目の概要の冒頭 140 文字（引用）と元記事へのリンクのみを収録しています。全文が必要な場合は `python -I scripts/build_catalog.py --full` でローカル生成できます（生成物は公開しないでください）。
- 外部 API の死活確認: `npm run check:endpoints`（GitHub Actions で毎週自動実行）。
- 各データの利用規約は提供元に従います（出典表記は地図下部のクレジット・各ビューの出典欄を参照）。
